# לוגואים של חברות הדלק

הקבצים כאן הם סימני מסחר של החברות ולכן **אינם** נשמרים ב־repo. הורידו את
הלוגו הרשמי מאתר כל חברה ושמרו אותו בשם המדויק שלהלן; הוא יופיע אוטומטית
בכל מקום שבו מוצגת התחנה (רשימת התחנות, פאנל הניהול). כל עוד קובץ חסר,
מוצגת מונוגרמה בצבע המותג — לא חיקוי של הלוגו.

| --------------- | --------- |

| `delek.svg`     | דלק       |
| `sonol.svg`     | סונול     |

- מומלץ SVG. PNG שקוף עובד גם — שנו את הסיומת ב־`src/components/StationBrand.tsx`.
- הלוגו מוצג בתוך ריבוע 34px על רקע לבן, עם `object-fit: contain`, אז מרווח
  פנימי בקובץ עצמו מיותר.
