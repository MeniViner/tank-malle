# לוגואים של חברות הדלק

הקבצים כאן הם **סימני המסחר של החברות**, לא נכס שלנו. הם משמשים לזיהוי התחנה
ברשימה בלבד — אותו שימוש שעושים Waze או Google Maps — ולא כמיתוג של האפליקציה.

| קובץ           | חברה     | מקור                                                    |
| -------------- | -------- | ------------------------------------------------------- |
| `paz.svg`      | פז       | he.wikipedia.org/wiki/פז קמעונאות ואנרגיה               |
| `delek.svg`    | דלק      | he.wikipedia.org/wiki/"דלק" חברת הדלק הישראלית          |
| `sonol.svg`    | סונול    | he.wikipedia.org/wiki/סונול                             |
| `dor-alon.svg` | דור אלון | he.wikipedia.org/wiki/דור אלון אנרגיה בישראל (1988)     |
| `ten.svg`      | טן       | he.wikipedia.org/wiki/טן חברה לדלק                      |

חברות נוספות שהמרשם מכיר (מיקה, תפוז, סד״ש, יעד) עדיין ללא קובץ, ולכן מוצגת
עבורן מונוגרמה בצבע המותג. להוספה: שמרו `mika.svg`, `tapuz.svg`, `sadash.svg`
או `yaad.svg` כאן והם יופיעו לבד — הרשימה והמונוגרמות ב־
`src/components/StationBrand.tsx`.

- מומלץ SVG. PNG שקוף עובד גם, אחרי שינוי הסיומת ב־`StationBrand.tsx`.
- הלוגו מוצג בריבוע 34px על רקע לבן עם `object-fit: contain`, אז מרווח פנימי
  בתוך הקובץ מיותר.
- אם חברה תבקש שנסיר את הלוגו שלה — מחיקת הקובץ מספיקה, והשורה חוזרת
  למונוגרמה בלי שינוי קוד.
