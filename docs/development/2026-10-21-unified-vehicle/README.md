## מה השתנה

הבית הקיים נשמר: צריכה וגרף, ממוצע ובסיס באותה שורה, למידה מהרגלי השימוש, מצב מיכל לא ידוע, תכנון נסיעה ותדלוקים אחרונים. תיקון בתחזית שומר את מלוא המרחק של נסיעה שעדיין מתוכננת להיום, גם בשעה מאוחרת, ואינו מציג אותה כדלק שכבר נצרך. מעליו נוספו מצב דלק, תחזוקה והוצאות חודש, עם קישורים לפירוט והתראות דחופות אמיתיות. נתונים חסרים נשארים חסרים. נוסח השוואת הצריכה תואם לחישוב הקיים של דלק לק״מ.

היומן מאחד תדלוקים, טיפולים, הוצאות, החזרים, קריאות מד־דרך ותקלות. אפשר לסנן סוג ותקופה, לחפש ולפתוח את רשומת המקור לעריכה או מחיקה. נשמרו ליטרים, צריכה מדודה, סימוני הפסקת רציפות ואגורות. בחירה בשנה פותחת את אותה שנה ביומן. ביטול מחיקה אחרי אישור השרת משחזר את המזהה המקורי.

אזור הרכב מחולק לתזכורות, תקלות, עלויות ופרטים. עורך הטיפול מדורג וכולל כמה עבודות בחשבונית אחת, טיוטות, עלות חסרה, מוסך ומועד המשך. לתקלה יש תסמינים, יום גילוי וק״מ, חשיבות, מצב, הערות וקישורים לטיפולים. עלות התיקון נספרת רק מהטיפול המקושר. נשמרים עשרת שינויי המצב האחרונים ועד שמונה טיפולים מקושרים לכל תקלה.

התראות שומרות נקרא/ארכיון/דחייה לכל מופע של תזכורת. ביצוע טיפול שומר אירוע אמיתי ומייצר מחזור חדש; דחיית הופעה אינה ביצוע טיפול או שינוי מועד התחזוקה. ביטול משתמש בכתיבה אמיתית ובבקרת גרסה. הגדרות ההתראות אינן מבטלות פעולות סנכרון.

תדלוק רגיל נשאר ברירת המחדל. העדפת ״פתח תמיד תדלוק מהיר״ נשמרת לחשבון. שני הצילומים מחוברים לקורא התצוגות המקומי הקיים, ללא חיתוך ידני או מודלים; כל תוצאה עוברת סקירה לפני שמירה. ייבוא טקסט ו־PDF עם טקסט נשאר מחובר לפענוח ולמניעת כפילויות הקיימים. נשמרו קלט ידני, ביטול צילום, החלפת רכב/חשבון והגנה מפני תוצאה מאוחרת.

העיצוב משתמש במשטחים ניטרליים, Rubik למספרים, קווי הפרדה, קבוצות שורות וגיליונות מדורגים, ללא מסגרת טלפון. פרופיל והגדרות זמינים מתפריט החשבון; הרשאות מנהל נשארו לפי האימות הקיים. קוד הדוגמה, המספרים העסקיים הקשיחים והפעולות המדומות מה־ZIP לא הועתקו.

## עובדות משותפות, חישובים וסנכרון

- VehicleDataProvider משתף את מנויי הרכב הפעיל ואת נגזרות היומן, העלות, הק״מ, התזכורות וההתראות. המסכים אינם פותחים עותק נוסף של כל מנוי.
- קריאת מד־דרך נלקחת מתדלוק, תצפית מיכל, טיפול או קריאה ייעודית, בלי לשמור עותק נוסף שלה. יום ללא שעה נשאר יום ללא שעה. סדר לא ידוע באותו יום אינו הופך לשעת אירוע מומצאת.
- גשר למנוע המיכל מוסיף ראיות יומיות בזהירות: אינו ממציא שעת נסיעה, הרגל לפי שעה/יום בשבוע, מצב מיכל מלא או מקטע צריכה. עמימות או ירידת מד־דרך מונעות יחס עלות/מרחק מטעה.
- עלויות מחושבות באגורות, החזר נגרע פעם אחת, ועלות חסרה אינה אפס. קניות דלק נפרדות מצריכה מדודה. התקופה והכיסוי מפורשים לפני הצגת יחסים.
- הבית, היומן, התובנות והרכב משתמשים באותה שכבה. בפרופיל הרכב הפעיל מתעדכן בזמן אמת; שאר הרכבים הם תמונת שרת עם שעת עדכון ורענון מפורש, כדי לא להאזין לכל הארכיון. ייבוא מרענן את הסיכום בסיום.
- outbox, מזהי כתיבה, אישורי שרת, ניסיונות חוזרים וסכסוכי גרסאות נשמרו. הודעת המתנה אינה הוכחת הצלחת שרת. נתונים חלקיים, מטמון ופעולות שלא סונכרנו מסומנים.

## גיבוי, שחזור ומחיקה

גיבוי חשבון JSON בגרסה 2 כולל את כל הרכבים, גם ארכיון; תדלוקים, תצפיות מיכל, תכנון נסיעות, ארבעת אוספי התחזוקה, תקלות, מצב התראות, העדפות ומידע ייבוא/מחיר רלוונטי. מזהים וקישורים נשמרים. נדרשת קריאת שרת תקינה; כשל אינו מוצג כגיבוי מלא.

תצוגת השחזור מפרידה רשומות חדשות, זהות והתנגשויות. היא מוסיפה רק חסרות ואינה דורסת תוכן קיים אחר. הוספה חוזרת אינה מכפילה. העדפות וטיוטות מקומיות משוחזרות רק בבחירה מפורשת, ולא מחליפות רכב פעיל או טיוטה קיימת אחרת. הקובץ מוגבל ל־8 MB ול־5,000 רשומות.

פעולות ממתינות נשמרות בנפרד בקובץ לצורך בירור; הן אינן מופעלות מחדש אוטומטית, כדי לא להחזיר מחיקה או כתיבה ישנה. תמונות אינן מועלות ואינן כלולות בגיבוי. כלי CSV/JSON/ICS הקודמים נשארו זמינים. מחיקת חשבון ורכב כוללת את שני האוספים החדשים ואת טיוטות התחזוקה השייכות לבעלים שנמחקו.

## גבולות וקבלה שנותרה

הבדיקות האוטומטיות כוללות את שתי התמונות שסופקו ואת Chromium/WebKit, לא מצלמה פיזית. שתי התמונות הן דוגמאות כיול ורגרסיה; הן אינן מוכיחות דיוק לכל משאבה, גופן, סנוור או מכשיר. אין כאן OCR כללי לקבלה מצולמת או ל־PDF סרוק. מסמכי ספק אמיתיים נוספים, Android ו־iPhone פיזיים דורשים קבלה של מני. אין משיכת נתונים פרטיים מאפליקציית דלק אחרת.

הטלפון דורש התקנת התעודה הציבורית ואמון בה, אותה רשת Wi-Fi והמחשב פועל. ההוראות וטביעת האצבע נמצאות ב־ACCEPTANCE.md. המפתחות הפרטיים, מקור התמונות ותוצרי בדיקה כבדים אינם ב־Git. לאחר סיום ההדגמה אפשר להסיר את אמון תעודת ההדגמה מהמכשיר.

אין הפעלת Functions, AI, מודלי OCR, העלאת תמונות, Cloud Storage או Push כשהאפליקציה סגורה. ICS הוא יצוא תאריך ללוח שנה, לא סנכרון או מתזמן שרת. היסטוריית הרכב הפעיל נטענת במלואה, ולכן משתמשים עם היסטוריה גדולה צורכים יותר קריאות; מכסות Spark הן לפרויקט כולו. לא נוספו תלויות ריצה בתשלום. [שיקולי Spark ותוכנית פריסה/חזרה תואמת](DEPLOYMENT-PLAN.md).

## שחזור ההדגמה במחשב

בתיקיית העבודה הייעודית, לאחר npm ci:

    PATH="/opt/homebrew/opt/openjdk/bin:$PATH" npx firebase emulators:start --only auth,firestore --project demo-tankmaleh --config firebase.unified-preview.json
    node scripts/seed-unified-demo.mjs
    npx vite build --mode unified-preview --outDir .care-device/unified-preview/dist
    npx vite preview --mode unified-preview --outDir .care-device/unified-preview/dist --host 127.0.0.1 --port 5293 --strictPort
    node scripts/unified-phone-preview.mjs 192.168.1.23

האמולטור והתצוגות הם תהליכים נפרדים; פותחים טרמינל נוסף לפי הצורך. seed מוסיף רק מסמכים חסרים ואינו מאפס או דורס. האחסון של אמולטור ההדגמה בתהליך אינו גיבוי קבוע: לשמור JSON אם משנים נתוני דוגמה שרוצים להחזיק לאחר עצירת האמולטור. אפשר להכין שוב את המדגם באמצעות seed. אין להריץ פקודות בדיקות שמאפסות אמולטור על פורטי ההדגמה.
