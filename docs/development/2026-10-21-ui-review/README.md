### קטגוריות בלי כפילות בחשבונית

הטקסונומיה המשותפת לטיפול ולתזכורת היא: טיפול תקופתי, שמן ומסננים, צמיגים, בלמים, מצבר, תיקון ואחר. ״טיפול תקופתי״ מתאר הקשר ויכול לחפוף לשמן/בלמים באותה חשבונית; בחירה בכמה עבודות אינה מכפילה את העלות. תזכורת מתארת את הטיפול הבא ואינה רישום הוצאה נוסף.

לא נוספה קטגוריית ״מוצרים״ עמומה שמתחרה בעבודות. חלקים כמו מגבים או מיזוג מתועדים ב״אחר״ עם תיאור; נוסף לכך רמז בתוך הבחירה. ביטוח, רישוי, חניה, אגרה, שטיפה והחזר נמצאים בהוצאות. אלה אותן קטגוריות שכבר מאושרות בסכמות, בגיבויים ובכללי האבטחה; לא נוצרו מרווחי טיפול אוטומטיים או המלצות יצרן מומצאות.
