# אימות סבב ההערות

הבדיקות משתמשות בפרויקט `demo-tankmaleh` ובפורטים חד־פעמיים 8087/9097 או 8088/9098. סביבת ההדגמה 8086/9096 נשמרת.

| בדיקה | תוצאה מקומית |
| --- | --- |
| יחידה, כולל שני הצילומים המצורפים | 693 עברו, 7 דולגו משום שקובץ Excel ההיסטורי הפרטי אינו זמין |
| כללי Firestore, אמולטור נפרד 8089 | 217 עברו |
| TypeScript ו־Production build | עברו |
| Lint | 0 שגיאות, 20 אזהרות קיימות; אין עלייה בתקציב |
| אינטגרציה, PWA, HTTPS ו־WebKit בריצה הסופית | 65 עברו, ללא דילוגים |
| בדיקות קבלה ממוקדות נוספות | 12 עברו: ששת התרחישים בשני דפדפנים, Chromium ו־WebKit |

בסבב הרחב הסופי עברו כל 65 התרחישים, כולל 41 Chromium, שלושה PWA, אחד HTTPS ו־20 WebKit. בריצות קודמות התגלו קדימות סגנון שהשאירה אריחים גדולים, חזרת פוקוס ב־Safari, תווית הערות המשתנה אחרי מילוי והסבר שמזיז את המחוג במהלך גרירה. אלה תוקנו; התוצאה הסופית לעיל מתייחסת לריצה חדשה אחרי התיקונים.

ברגרסיות הוותיקות נבדקו 137 תרחישים, מהם שניים שדורשים Excel פרטי ומדולגים. התרחישים עודכנו לפתיחת סקשן המיכל לפני בחירת מצב סיום ולניסוח המקטעים שביקש מני. כישלונות מהתאמת הפקדים הישנים אינם מוצגים כהצלחה; תוצאות הריצה המלאה ב־CI של קומיט השחרור נמסרות בתשובת הסיום. בדיקת 25% כוללת גם וידוא שמיקום המסלול לא משתנה במהלך הגרירה.

הרגרסיות הממוקדות ב־`e2e/ui-review.spec.ts` מכסות מיכל קומפקטי, נתוני הרגלים חסרים, חישוב סכום דו־כיווני, כיווץ אחד ללא סימון מלא אוטומטי, טבעת פוקוס אחת, תפריט בשורות מלאות, סגירה ב־Escape וחזרת פוקוס, ציר גרף המתחיל ב־0, יישור סכומים לימין, שמירת מספר עבודות בטיוטה ומתג אחיד עם שמירת העדפה.

הבדיקות הרחבות הקיימות מכסות בנפרד החזרים, עריכה/מחיקה/Undo, שחזור גיבוי, הפרדת חשבונות ורכבים, טיוטות ואופליין, ייבוא PDF/טקסט וכפילות מדויקת, הרשאות מצלמה ועצירת זרמים. התמונות שסופקו נקראו ללא בחירה ידנית של אזור: 202.73 ₪ / 26.092 ל׳ ו־171272 ק״מ. אלו שתי דוגמאות ולא הבטחת דיוק כללית.

פקודות שחזור:

```sh
CARE_PUMP_PHOTO=... CARE_ODO_PHOTO=... npm test -- --reporter=dot
RULES_FIRESTORE_PORT=8089 npx firebase emulators:exec --only firestore --project demo-unified-rules --config firebase.rules-isolated.json 'npx vitest run --config vitest.rules.config.ts'
E2E_ISOLATED=1 npx playwright test --project=chromium --project=pwa
CARE_WEBKIT_PATH=... npx playwright test --config=playwright.unified.config.ts --project=unified-chromium --project=unified-webkit --grep 'Home has|both amount|period lists|care is compact|every setting|known monthly'
```

תוצאות CI קשורות ל־SHA המדויק ב־GitHub. ה־workflow מפעיל שוב את רגרסיות האינטגרציה המלאות ב־Chromium, את ה־PWA ואת שער ה־HTTPS. הוא אינו מפעיל מצלמה פיזית; מקרי צילום פרטיים שאינם נמצאים ב־CI מדולגים שם במפורש. כתובת הריצה ומזהה הגרסה שפורסה נמסרים בתשובת הסיום.

בדיקת הגרירה נוספה גם היא לסבב הרחב: אחרי קיפול כל פרטי המיכל יחד, הסבר שהשתנה מעל המחוג הזיז את המסלול תוך כדי גרירה. ההסבר הועבר מתחת למחוגים, הוסרה התראת סתירה כפולה ונוספו פוקוס ללא גלילה ובדיקה שמיקום המסלול נשאר יציב. ניסוח ספירת המקטעים בבית עודכן בהתאם להערת מני.
